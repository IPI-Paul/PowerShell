# IPI Windows Icon Picker

Lately I have been making good use of ChatGPT to develop solutions using Python, PowerShell, C# and C++. For my PowerShell solutions I wanted a way to use the same icons in the WPF forms as the Windows shortcut links.

So, I asked ChatGPT to build it for me. It did two versions, but on the second version omitted some crucial logic it already got right in the first version. So, it was an easy fix.
